# Make `exedra` the suite facade over `exedra_mesh`

Rename the current half-edge mesh crate to `exedra_mesh` and introduce a leaf-only `exedra` facade that presents the stable application-facing heads without moving their implementations or hiding conversion boundaries.

## Design

`exedra_mesh` owns mesh topology, attributes, mutation invariants, Boolean machinery, and render extraction. `exedra` owns only feature selection, curated namespaced re-exports, anchor types, and end-to-end documentation. Implementation crates depend on `exedra_mesh`, never upward on `exedra`. The facade defaults to the common standard-library constructive, assembly, and operations surfaces; specialist and no-std consumers may depend on focused crates directly. Analytic, isosurface, primitive-generator, and export surfaces remain opt-in.

## Acceptance Criteria

The old mesh implementation and docs live under `exedra_mesh`; every implementation dependency and Rust path names it honestly; a new `exedra` facade defines no geometry algorithms or state; default, minimal, no-std, per-head, and all-feature configurations compile; a mixed recipe/mesh assembly example works through the facade; CI enforces the dependency direction; formatting, spelling, lint, tests, and rustdoc pass.
