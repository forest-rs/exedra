# 2D scalar-field profiles

Add a small 2D field seam plus core profile primitives so exedra_isosurface can build richer implicit shapes from profiles instead of only hand-written 3D SDFs.

## Design

Introduce ScalarField2d alongside the existing 3D ScalarField contract. Start with calm reference primitives that are broadly useful for tests and construction: CircleField2d, RectField2d, and HalfPlaneField2d. Mirror the 3D contract where it is useful but keep the representation simple and no_std-friendly. Use these profiles as the basis for later lifting operators such as extrude and revolve.

## Acceptance Criteria

1. exedra_isosurface exposes documented ScalarField2d plus core analytic 2D primitives. 2. Point and gradient evaluation for the reference profiles are covered by deterministic tests. 3. Interval evaluation is conservative for sample boxes/rectangles. 4. Public docs explain the sign convention and the intended relationship to 3D ScalarField. 5. Full quality gates for the touched crates pass.
