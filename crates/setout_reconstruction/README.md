# setout_reconstruction

`setout_reconstruction` interprets Setout's structural provenance as a historical
reconstruction. It catalogs sources and calculation warrants, folds them into
claim assessments, and reports limiting premises without changing arithmetic or
selecting an operative claim.

The sidecar is deliberately separate: the same exact setting-out network can be
used for a basilica reconstruction, a machine fixture, or a publishing imposition
without inheriting historical-evidence policy.
