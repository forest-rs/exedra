# v0.1 Critical Path and Sequencing

Date: 2026-03-03
Owner: exedra/cambium workspace

## Goals

- Ship one thin, credible end-to-end slice before broader feature breadth.
- Prove the Exedra/Cambium boundary with real code, not only specs.
- Keep sequencing deterministic and low-WIP.

## Non-goals (for first slice)

- UV projection vertical slice (`cam-v5ko`).
- `exedra_primitives` breadth (`ep-*` shape catalog).
- Boolean pipeline and advanced operators.

## Sequencing Decision

- **Phase 1 (now):** kernel foundations, transactions, minimal operator runtime, and region tag/select composition.
- **Phase 2 (after Phase 1 is green):** UV planar and primitive catalog.

Operational adjustment made:
- `cam-v5ko` and all `ep-*` tickets are set to `priority: P2` and tagged `phase2`.
